# More Than A Hack 2027: бриф команды

Хакатон по футбольной аналитике от Metrica Sports, FC Barcelona (Barça Innovation Hub) и Mobile World Capital Barcelona. Данные реального матча LaLiga: «Барселона» против «Атлетика», сезон 2024/25.

## Задача

Для каждого из 199 319 кадров матча указать, у кого мяч: `H` (Барселона), `A` (Атлетик), `D` (мяч вне игры) или `X` (нет ответа). Результат проверяется автоматически, жюри нет.

Метрика рейтинга spellF1 считает владения целиком: каждое владение засчитывается, если наш отрезок совпал с настоящим по времени. Поэтому важно не дробить владение на мелкие куски.

Порог для прохода дальше: базовое решение организаторов набирает 0,2433. Топ-20 команд проходят во второй этап (26.11.2026 – 14.01.2027, онлайн, 10 матчей). Топ-5 едут на финал в Барселону 02.03.2027, перелет и проживание оплачивают организаторы.

## Регистрация

1. Форма: https://landing.mobileworldcapital.com/more-than-a-hack-2027
2. Название команды: **Solomon's Team**. Пишите точно так же.
3. Примите условия использования данных в форме.

Команда из 3–5 человек. Если нас меньше трех, во второй этап не пускают.

## Правило про ИИ (обязательно)

Условия запрещают передавать данные соревнования в любой внешний ИИ-сервис: ChatGPT, Claude, Gemini и другие.

• Нельзя вставлять в чат строки трекинга, тэгинга, графики, кадры видео, таблицы с числами из матча.
• Можно спрашивать ИИ про код и методы, если в вопросе нет данных матча.
• Данные храним только локально, в публичный репозиторий не коммитим.

Нарушение означает дисквалификацию всей команды.

## Другие правила

• Метки только из алгоритма. Ручная разметка этого матча запрещена в любом объеме.
• Публичные 5 минут разметки нужны для проверки, что пайплайн собран правильно. Обучаться и подбирать параметры на них нельзя.
• Обучение и подбор параметров только на других матчах. Сейчас это три открытых матча Metrica.

## Что уже сделано

Репозиторий с пайплайном: загрузка трекинга, признаки по командам без идентификаторов игроков, классификатор, декодер Витерби, который склеивает владения. На трех открытых матчах Metrica с искусственным шумом (мяч пропадает на 41% кадров, как в данных соревнования) решение набирает spellF1 около 0,47 против 0,24 у базового решения.

## Как начать

1. Попросите у Жанторе доступ к приватному репозиторию (публичным он станет при сдаче).
2. `python -m venv .venv`, затем `pip install -r requirements.txt`.
3. Внешние данные: `git clone https://github.com/metrica-sports/sample-data external/metrica-sample-data`.
4. `python -m mtah.bench` показывает результат на внешних матчах. Улучшение засчитываем, только если оно больше 0,04 по spellF1.
